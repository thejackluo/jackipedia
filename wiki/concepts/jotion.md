# Jotion

**Category:** Concepts / Tools / Personal OS
**Summary:** Jack's personal Notion system — "Jotion V4.5" — the operating system for his life
**Last updated:** 2026-04-06

## Overview

Jotion is Jack's name for his personal Notion workspace. Currently on version V4.5, it is not a simple note-taking system — it is a fully structured personal operating system covering every domain of his life: writing, meetings, media, fitness, running, travel, and more.

The name "Jotion" appears to be a portmanteau of Jack + Notion, or perhaps just Jotion as a distinct identity for the system.

## Architecture

Jotion V4.5 is built around linked databases:

| Database | Contents | Notes |
|----------|----------|-------|
| Writings Database | 360+ entries, 2021–present | Essays, reflections, dream journals, daily logs, ideas |
| Meetings Database | 50+ meeting notes | Granola-sourced transcripts + manual entries |
| Media/Books Database | 40+ books tracked | Ratings, progress, summaries, categories |
| Fitness Hub | Workout logs | Gym sessions, runs |
| Running Database | 20+ logged runs | Strava-connected, speed/distance/weight |
| CRM / People | Contact notes | Relationship intelligence (the AgentDex precursor) |

## The Writings Database

The most important database. 360+ entries spanning 2021–2026 with a Michelin-style quality rating system:

- **3 Stars**: Exceptional writing, worth a special journey
- **2 Stars**: Excellent writing, worth a detour
- **1 Star**: Very good writing, worth a stop
- **Bib Gourmand**: Good quality, casual and noteworthy

Tags include: Essay, Note, Reflection, Idea, Log, Academic, Personal, Startup, Creative, Events, High School.

The dream journals are tagged Log + Personal and rated Bib Gourmand. The major essays (Walk in the Park, Annual Reviews) are 2–3 stars. Day-to-day logs are unrated or 1 star.

The Michelin rating system applied to personal writing is one of the more distinctive things about Jack's approach. Most people either don't rate their own work or use a simple 1–5 stars. The Michelin system has specific qualitative meaning at each level — not just "how good is this" but "what kind of effort does it merit from a reader."

## The Meetings Database

Used with [[concepts/granola]] for AI-powered transcription. Every significant meeting gets captured:

- Title + date
- Meeting type (1:1, Team Sync, Brainstorm, VC)
- Summary
- Decisions Made
- Action Items
- Tags (Important, Startup, Reference, Follow-up Needed)
- Confidence (Human Reviewed vs. AI Summarized)
- Source (Granola vs. Manual)

This is the raw material for [[projects/jackipedia]]: the meetings database is one of the primary sources for the people and history sections.

## The Running Database

20+ logged entries from summer 2021. Each entry has: date, location, distance (miles), time (min), speed (mph), weight (lbs), difficulty rating, and a written description. The descriptions are remarkably honest — "I am just dying in general with my running" (Day 12), "my fastest run in a while, and I really tried" (Day 15).

This database is covered in more detail at [[fitness/running-project-2021]].

## V4.5 as a Version Number

The version number (V4.5) implies previous versions: V1, V2, V3, V4. Each version presumably had a different architecture as Jack's needs evolved. Version 4.5 is the current stable release, with the home page at "Jotion V4.5 Home."

This is consistent with treating a personal productivity system like software: you iterate, break things, migrate data, and eventually arrive at something stable enough to run for a while.

## Connection to AgentDex

[[projects/agentdex]] (ROLO) is in some ways a productized version of the CRM component of Jotion — the people/relationships layer, made intelligent and automated. The journey from "Jack manually maintains a Notion CRM" to "what if this were AI-native and could help anyone" is the AgentDex founding insight.
